TIDAL FRONTIER 3D — SEPARATE REPOSITORY

Upload ALL files in this ZIP to the ROOT of your new GitHub repository (not the ZIP itself).
Render: New Web Service, Node, Build Command: npm install, Start Command: npm start.
Visit your Render root URL / to open 3D directly. /3d.html also works.

The 3D world is a basic prototype using Three.js loaded from jsDelivr. Internet and WebGL are required.
The world is playable without login; clan create/join requires an account token. Clan system is not independent of the original account flow yet.

IMPORTANT: This is not photorealistic. Fish catches are demo only, and multiplayer character syncing is not implemented. Clan data on Render needs persistent storage (CLAN_DATA_FILE).
